# LINE風トーク画像メーカー v2

公開中の現行版を変更せず、別URLで動かす改善版です。

- 現行版: `/line-talk-maker/`
- 改善版: `/line-talk-maker/v2/`

## 保存方式

ユーザーと案件のデータはブラウザの `localStorage` に保存します。画像を含む案件はJSONファイルとして書き出し・読み込みできるため、別端末への移動やバックアップも可能です。

GitHub Pagesは静的サイトなので、メールアドレスやパスワードを使う本格的なユーザー認証・クラウド同期は含めていません。これらが必要な場合はSupabaseなどの認証・データベースを追加してください。

## 台本の形式

```text
相手：お世話になっております。
自分：こちらこそ、ありがとうございます。
相手：明日の件ですが…
自分：10時でお願いします。
```

Google Sheetsから話者列とセリフ列をコピーした、タブ区切り形式を優先して読み込みます。貼り付け後に抽出された話者から「主人公」を選ぶと、その話者が自分側に配置されます。`【時間経過】` の行は、画像に表示しないシーン区切りとして取り込みます。

台本用画像は、ファイル名に①②③…の通し番号を入れてまとめて選択します。台本内の `【画像】` へ番号順に挿入し、画像の送信者は直前のセリフと同じ側に設定します。台本内で最後に出現する `【画像】` と、それに対応する最後の画像ファイルはLINE画面に挿入しません。挿入後もメッセージ一覧から送信者の切替や画像の変更ができます。

`話者: セリフ`、任意の話者名、話者名なしの行にも対応します。読み込み後は一覧上で時刻と自分側の既読を即時変更できます。

## 時刻の設定

各シーンには「開始時刻」と「間隔」があり、適用ボタンを押したときだけ、そのシーン内の時刻をまとめて更新します。既定の間隔は0.5分で、2件ごとに1分進みます。間隔は0.5分刻みで変更でき、個別の時刻は従来どおり一覧上で微調整できます。

任意の開始メッセージと終了メッセージを選び、次の4種類の一括変更もできます。

- 開始時刻から一定間隔で設定
- 全件を同じ時刻に設定
- 現在の間隔を保ったまま前後に移動
- 開始時刻から終了時刻まで均等に配置

適用前に変更予定を確認でき、直前の時刻変更は「元に戻す」で取り消せます。

メッセージ一覧の「自分 → 相手」「相手 → 自分」ボタンを押すと、編集画面を開かずに送信者を即時切り替えられます。
